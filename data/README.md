# data/

Put the dataset file here.

1. Download **Default of Credit Card Clients** from the UCI Machine Learning Repository:
   <https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients>
2. Unzip and copy `default of credit card clients.xls` into this folder (keep the name).

The loader also accepts `UCI_Credit_Card.csv` (the popular Kaggle copy of the same data).

Full instructions, the data dictionary and known quirks are in [`../docs/01_dataset_guide.md`](../docs/01_dataset_guide.md).
